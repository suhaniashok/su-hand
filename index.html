Alternates

small letters,

better mornings

the week between

No letter sets the same shape twice, and some doubles join up. Hover a line to rewrite it.

Handwriting, roughly kept as it fell

Handwriting, roughly kept as it fell out of the pen

Set it long and it keeps moving. No two of the same letter fall the same way, the doubles lean into each other, and a page of it still looks written rather than typed. It wants room to do that: the ascenders and descenders run long against the x-height, so 1.5 line height is the floor rather than the ceiling.
